# Appendix C: Surface Science & Characterization Specifications

| Parameter | In-Situ XPS System | Time-of-Flight SIMS (ToF-SIMS) |
| :--- | :--- | :--- |
| **X-ray Source** | Monochromatic Al K$\alpha$ ($1486.6\text{ eV}$) | Pulsed Liquid Metal Ion Gun ($\text{Bi}_3^{++}$) |
| **Energy Resolution** | $<0.45\text{ eV}$ (FWHM on $\text{Ag } 3d_{5/2}$) | Mass resolution $m / \Delta m > 10,000$ |
| **Sampling Depth** | $1\text{ to } 8\text{ nm}$ (inelastic mean free path) | Top $1\text{ to } 2\text{ monolayers } (<1\text{ nm})$ |
| **Detection Limit** | $0.1\text{ atomic } \%$ | Parts-per-million to parts-per-billion |
| **Base Pressure** | $<5 \times 10^{-10}\text{ Torr}$ | $<2 \times 10^{-10}\text{ Torr}$ |
| **Sample Capability** | Full $300\text{ mm}$ wafer or coupon | Full $300\text{ mm}$ wafer |
| **Analysis Modes** | Core-level, valence band, Angle-Resolved (ARXPS) | Surface spectroscopy, 2D mapping, depth profiling |
